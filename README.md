# Netflix User Behavior & Engagement Analysis

## Project Overview

This project analyzes Netflix user behavior, content preferences, engagement, subscription patterns, and customer churn using an interactive Power BI dashboard.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel

## Key Analysis

- User demographics
- Genre preferences
- Device usage
- Customer churn
- Subscription analysis
- User engagement

## Key Insights

- Most viewers are from Brazil.
- Documentary is one of the most-watched genres.
- Mobile devices are commonly used by viewers.
- User engagement varies across subscription types.
- A significant portion of users have churned.

## Dashboard

The dashboard provides interactive analysis of Netflix users, including genre preferences, churn status, device usage, subscription type, and user engagement.
